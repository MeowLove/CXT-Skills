# ChatGPT / Codex Client Backups

This directory stores configuration files, model-cache backups, and recovery utilities related to the ChatGPT/Codex client environment.

These files can help repair or restore normal Codex operation, especially when models or client settings are missing, corrupted, or reset after an update.

## Contents

- Backup archives and file-management tools
- Client update and recovery scripts
- Model and configuration snapshots

## Usage Notes

1. Close the ChatGPT/Codex client before restoring files.
2. Keep a copy of the current client data before replacing anything.
3. Restore only the files relevant to the reported problem.
4. Review scripts before running them and use an elevated terminal only when required.

This is a local recovery collection, not an official ChatGPT or OpenAI distribution. Always obtain the client itself from an official source.
