# CXT-Skills

Personal backup repository for practical Agent skills, client recovery files, and Windows/Linux workstation utilities.

The repository is organized as three independent projects. Each project has its own documentation and can be used separately.

## Projects

| Project | Purpose | Documentation |
| --- | --- | --- |
| [`ChatGPT`](https://github.com/MeowLove/CXT-Skills/tree/main/ChatGPT) | Configuration files, model-cache backups, and recovery utilities for the ChatGPT/Codex client. Useful for restoring missing models or damaged client settings. | [`ChatGPT/README.md`](https://github.com/MeowLove/CXT-Skills/blob/main/ChatGPT/README.md) |
| [`DoubaoImeManager`](https://github.com/MeowLove/CXT-Skills/tree/main/DoubaoImeManager) | PowerShell-based manager for discovering, downloading, verifying, installing, and uninstalling the official Doubao IME Windows package. | [`DoubaoImeManager/README.md`](https://github.com/MeowLove/CXT-Skills/blob/main/DoubaoImeManager/README.md) |
| [`linux-agent-env`](https://github.com/MeowLove/CXT-Skills/tree/main/linux-agent-env) | Portable Skill for preparing Linux and WSL Agent workstations, including locale/fonts, developer tools, Agent CLIs, provider operations, diagnostics, and resumable session workflows. | [`linux-agent-env/README.md`](https://github.com/MeowLove/CXT-Skills/blob/main/linux-agent-env/README.md) |

## How to Use This Repository

1. Open the project directory that matches your task.
2. Read its local `README.md` and any referenced instructions before running scripts.
3. Install or copy only that project and its required files.
4. Keep backups of current configuration before applying recovery or system changes.

These projects are maintained as independent utilities. Their scripts may change client data, install software, modify WSL settings, or require administrator privileges; review the project-specific safety notes before execution.

## Repository Scope

This repository is a personal collection and backup, not an official distribution of ChatGPT, Codex, Doubao IME, Linux, WSL, or any third-party Agent platform. Use official upstream sources for the software itself and keep credentials, tokens, and private authentication files out of the repository.
